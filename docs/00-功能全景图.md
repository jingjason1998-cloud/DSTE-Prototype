实现形态说明：

- **cockpit 内页**：`src/cockpit.html` 的 `PAGES{}` 路由渲染（SPA 主页面）。

> - 驾驶舱：预算执行看板汇总关键指标。

## 三、关键约束

- 继续沿用现有架构：`cockpit.html` 作为 SPA 主页面，独立页面在 `vite.config.js` 注册入口、在 `config.js` 的 `EXTERNAL_PAGES` / `PAGE_META` 登记后以 iframe 嵌入工作区。
- `cockpit.html` 的 JS 在 IIFE 中，局部函数不能被 `onclick` 直接访问；页内交互优先使用事件委托或 `window` 暴露全局函数。
- CSS 继续使用变量（`var(--primary)` 等），禁止硬编码颜色。
- 每阶段完成后应跑 `npm run build` 和核心 Playwright 用例，确保无新增回归。
