条目统一模板

每个专项规划一个文件(如 教育发展.md),约 80–120 行:

  1. frontmatter:tier: T2、credibility: official、topics 含专项领域、 pest 按内容关联;source 为印发机关(如 国务院 / 国家发改委 国家能源局)
  2. 一、定位与目标(核心量化指标小表,未公开标 —)
  3. 二、重点任务(按原文结构提炼,5–10 条)
  4. 三、重大工程/专项行动(如有,3–8 条)
  5. 四、与《纲要》的衔接点(对应《纲要》篇/章,2–4 条)
  6. 五、来源(全文官方 URL、文号、印发日期)
