省级条目统一模板

每个省条目(如 广东.md)结构如下,约 100 行:

  1. frontmatter:region: <省份>、tier: T3、credibility: official、其余按 AGENTS.md 规范
  2. 一、发展定位(官方定位表述)
  3. 二、主要目标:核心指标小表(GDP 年均增速/2030 总量、研发强度或研发经费增速、 城镇化率、特色指标;未公开标 —)
  4. 三、重点产业与新赛道(5–10 条,官方提法)
  5. 四、重大工程/重大平台(5–8 条)
  6. 五、与国家《纲要》的衔接点(承担的国家战略、国家重大工程落点,2–5 条)
  7. 六、来源(全文官方 URL、印发日期、篇/章数)
