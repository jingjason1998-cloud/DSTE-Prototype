PEST 宏观洞察框架

本文件定义 insights/ 的工作框架:四维度定义、观察议题清单、维度总览写作规范、周期报告模板。

元数据说明

  • credibility: analysis —— insights/ 下文件的专用取值,表示内部分析产物(基于 knowledge/ 官方来源的二次判断),不是原始信源。AGENTS.md 元数据规范中的 official / state-media / thinktank 三档描述的是信源性质,不适用于本目录。
  • 判断日期写在每条判断尾部(格式 — 2026-08-04),frontmatter 的 retrieved 记文件最近一次整体更新日期。

二、观察议题清单

每个议题尽量落到可跟踪的数字、机制或时间节点,作为周期报告的固定跟踪项。

P · 政策与治理

  1. 规划法治化落地:《国家发展规划法》2026-03-12 施行后,配套法规政策制度建设进展(topics/18 第六十二章"完善国家发展规划法配套法规和政策制度体系")。
  2. 全周期实施机制运转:约束性指标责任分解、年度计划衔接、动态监测;首个观察节点为规划期中期评估(依法向全国人大常委会报告)。
  3. 宏观政策取向一致性:规划作为一致性评估依据的实际执行;中央财政资金是否"优先投向"规划重大任务。
  4. 统一大市场制度供给:全国统一大市场建设条例制定、招商引资鼓励/禁止事项清单、市场准入负面清单动态修订。
  5. 财税改革节奏:消费税征收环节后移并稳步下划地方、零基预算改革、提高直接税比重的推进次序。
  6. 安全治理部署:粮食/能源/产业链安全能力建设(专栏23 六项工程)、反制裁反干预反"长臂管辖"机制化。
  7. 监督与考核:差异化考核评价、规划实施情况向社会公开的颗粒度。

E · 经济

  1. 增长目标设定方式:GDP 不设五年定量目标("保持在合理区间、各年度视情提出",2025 年基期 5%)与 2035 年人均 GDP 中等发达国家远景之间的张力;每年年度目标的实际取值。
  2. 研发投入双口径:全社会研发经费投入年均增长 >7%(不变价,2025 年增速 9.1%)与"十四五"末研发强度 2.8%——经费增速持续高于名义 GDP 增速则强度被动抬升,跟踪年度强度公布值。
  3. 消费率提升:"居民消费率明显提高"(定性目标)与提振消费专项行动、城乡居民增收计划的落地组合。
  4. 数字经济占比:数字经济核心产业增加值占 GDP 比重 10.5%(2024 年)→ 12.5%(2030 年),五年 +2 个百分点。
  5. 城镇化:常住人口城镇化率 67.9% → 71%,农业转移人口市民化("常住地登记户口""人地钱挂钩")配套进展。
  6. 产业结构:制造业"保持合理比重"的政策含义;未来产业 10 赛道(集成电路、具身智能、生物制造、新型电池、商业航天、国产大飞机、低空装备、绿色氢能、脑机接口、高端医疗器械)的培育进展;"内卷式"竞争整治。
  7. 绿色约束指标:单位 GDP 二氧化碳排放累计降 17%、非化石能源占比 21.7% → 25%(均为约束性),碳排放双控制度实施。
  8. 制度型开放:服务业准入扩大(电信、互联网、教育、文化、医疗试点)、加入 CPTPP/DEPA 进程、人民币国际化安排。

S · 社会

  1. 生育支持政策包:育儿补贴与个税专项附加扣除、补贴标准动态调整机制、3 岁以下婴幼儿入托率五年提高〔6〕个百分点。
  2. 老龄化应对:养老机构护理型床位占比 68% → 73%、渐进式延迟法定退休年龄实施、长期护理保险推行、银发经济。
  3. 就业目标与结构矛盾:城镇调查失业率 <5.5%(各年度);职业技能培训与"新八级工";人工智能对就业影响的综合应对(第十二篇与第四篇"强化人工智能的就业创造效应"交叉观察)。
  4. 收入分配改革:居民收入增长与 GDP 增长同步、劳动性所得统一征税、橄榄型分配格局。
  5. 人力资本指标:劳动年龄人口平均受教育年限 11.3 → 11.7 年(民生类唯一约束性指标);学前教育毛入园率 95%、高中阶段完成率 88%、高等教育毛入学率 65%。
  6. 健康目标:人均预期寿命 79.25 → 80 岁;每千人口执业医师 3.1 → 3.7 人、注册护士 4.3 → 5.1 人。
  7. 房地产新模式:现房销售、项目公司制与融资主办银行制、保障性住房供给——房地产从增长引擎叙事转入民生篇目。
  8. 文化建设:主流媒体系统性变革、文化产业新业态(微短剧、沉浸式展演)、中华文明传播力工程(专栏14)。

T · 技术

  1. 关键核心技术攻关:集成电路、工业母机、高端仪器、基础软件、先进材料、生物制造六大领域"采取超常规措施……取得决定性突破"的进展与政策工具("揭榜挂帅""赛马"、以奖代补)。
  2. 研发投入结构:经费年均 >7% 之外,跟踪"基础研究经费投入占研发经费投入比重明显提高"的年度公布值——结构目标比总量目标更软,是观察重点。
  3. 专利质量:每万人口高价值发明专利拥有量 16 件 → >22 件(2030 年)。
  4. "人工智能+"行动:专栏10 部署方向落地;超大规模智算集群论证建设、国家人工智能创新高地与应用中试基地。
  5. AI 治理框架:算法备案、透明度管理、安全评估、全生命周期风险管理制度的建立节奏;政务领域大模型部署的"安全稳妥有序"口径。
  6. 数据要素制度:数据产权结构性分置、全国数据资源"一本账"、全国一体化数据市场与价格形成机制。
  7. 科技金融:债券市场"科技板"、国家创业投资引导基金、国家级并购基金、"投早投小投长期投硬科技"政策。
  8. 教育科技人才一体化:人工智能、集成电路等急需学科"超常规布局"、新型研究型大学、高技术人才移民制度。

三、维度总览文件写作规范

适用于 P-political.md、E-economic.md、S-social.md、T-technological.md。

  1. 每条判断 = 判断句 + 证据链接 + 判断日期,三要素缺一不可。
    • 判断句:一句话给出分析结论,可带限定条件;避免抄篇目标题或罗列要点。
    • 证据链接:相对路径指向具体 knowledge 条目(维度总览位于 insights/ 根下,路径形如 ../knowledge/topics/03-科技自立自强.md);一条判断可挂多个证据,鼓励跨条目交叉引用。
    • 判断日期:格式 — YYYY-MM-DD,为该条判断形成/最后确认日期。
  2. 区分两种陈述:
    • 纲要/官方文件明确表述:直接引用或概括原文,证据即原文条目;
    • 分析推断:在句内以"(分析推断)"标注,说明推断依据;推断不得脱离知识库已有证据。
  3. 数字必须与 knowledge/ 条目一致;引用前先核对 indicators/main-indicators.md 等一手条目。发现 knowledge 疑似错误时,不照抄,在判断中或文件"存疑记录"小节标注。
  4. 每条判断控制在 2–4 句;单个文件"当前关键判断"保持 5–12 条,超出时把旧判断降级为"历史判断"归档或合并。
  5. 更新判断时同步更新 frontmatter 的 retrieved 日期;不要删除带日期的旧判断而不留痕(周期报告依赖历史判断做边际变化对比)。
